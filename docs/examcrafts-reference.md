# Examcrafts 参考记录

核实日期：2026-10-08。目标：https://examcrafts.com/。

验证：构建、7 项单元／交互测试通过；桌面与手机的 4 项 Playwright 测试通过（离线测试环境）。测试浏览器安装于 `D:\CodexTools\playwright-browsers`，运行测试时设置进程环境变量 `PLAYWRIGHT_BROWSERS_PATH` 为此路径。未修改系统环境变量或云端账号配置。

浏览器加载到页面标题，但控制接口连续超时。使用 HTTP/1.1、TLS 1.2 读取公开首页及首页引用的 JavaScript 后成功；以下是公开界面资源证据，未登录实测评分、题库数量和账号功能。

## 已从官网资源确认

- `CETSelectView`：四级／六级整卷，按年份筛选，题卡标注套数。
- `CETTopicSelectView`：听力、选词填空、段落匹配、阅读理解、写作、翻译专项；显示预计时间与题量，按年份和考试月份选择，保存筛选条件。
- `CETExamView`：听力、阅读、写作与翻译分区；提示划词翻译、高亮标记和添加生词本；客观题提交与主观题评分分别处理。
- `MistakeCollectionView`：错题合集、词汇本、听力／阅读／写作／重要错题分类；按更新时间、题量、掌握率、名称排序；解析页可加入错题合集。
- 首页导航包含生词本、笔记本；官网简介明确列出 AI 评分与知识图谱。知识图谱资源对应考研数学，不应直接描述为英语知识图谱。

开发者公开介绍补充了全科模拟、作文／翻译 AI 评分及优化建议、辅助阅读和考研 AI 助教：[公开介绍](https://www.douyin.com/video/7579440011171417353)。评分质量与当前使用额度没有核实。

## 本次落实

- 口语接入现有内容库的视频、音频、文章，支持搜索、类型筛选、复述练习，保留录音回放与自评。
- 题目按目标、题型、难度和标题／来源筛选。
- 逐题练习可核对并锁定本题，计时测试提交后统一展示解析。
- 答题卡显示已答进度并跳转题目；沿用已有保存、恢复、判分与错因记录。

## 后续完整考试能力需要的真实输入

- 年份、月份、套数筛选需要带这些元数据的真实题包；现有题包为原创／来源训练，不添加虚构年份。
- 选词填空、段落匹配、写作、翻译需要扩展题型数据与作答、评分流程；本次没有建立空模块。
- 逐句音频与同步字幕需要真实时间轴，不能靠文本猜时间。
- 英语作答页划词工具可复用内容页的词典与收藏逻辑；错题合集可在现有复习数据上扩展。
