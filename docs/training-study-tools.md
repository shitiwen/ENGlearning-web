# 训练学习辅助

## 训练页查词与生词收藏

在阅读材料、题目、答案解析或听力原文中选中英文单词或短语，会打开语境词卡。真题 PDF 请展开“当前页文字视图（可选词）”。没有文字层的扫描页需要查看原卷图像。

默认只查内置英汉词典，不自动调用付费 AI。确认或修改“此处含义”后收藏，词条与原句、练习来源一起加入原有生词本和到期复习队列。词典读取失败时可重试或手动填写。需要完整词卡时，可主动点击 AI 语境解释；会发送所选文字和原句、使用个人 API 额度。

## 听力回放和字幕

播放器支持速度选择、逐句定位、单句循环与当前句提示。计时测试交卷前隐藏字幕和原文；逐题练习及交卷后可使用逐句复习。

现有音频没有全部配好时间轴。可以导入与音频对应的 WebVTT / SRT 文件，或边听边点击“记录句首”“记录句尾”建立真实时间轴。系统不会按字数估算时间；导入时检查时间顺序、重叠和已知音频时长。导入失败保留此前字幕。时间轴保存在当前训练记录，回看这次记录时可以继续使用。

题包可包含 `captions: [{ start: 1.2, end: 3.5, text: 'The exact spoken sentence.' }]`；时间单位为秒，必须对应真实音频。原文自身不代表有时间轴。

## AI 批改独立于交卷

写作、翻译先保存交卷，再由用户主动发起 AI 批改。整卷中的写作与翻译各自有批改入口和状态，不覆盖客观题成绩。

批改等待期间可以返回列表，继续训练；当前标签页仍保持打开时请求会继续，并自动保存结果。失败、超时可重试，旧反馈与已保存作答仍保留。重复点击不会重复发起同一任务。关闭标签页或刷新会中断浏览器请求，重新打开记录后超时任务会转为可重试状态；这不是服务端离线任务队列。

真题反馈使用已浏览原卷页的提取文字。请浏览完整题目要求；扫描页没有可提取文字时，在批改入口填写完整题目内容。未填写的部分不能发起批改。反馈是学习建议，不是官方分数。

## 错因与下一步

交卷后为错题选择词义、定位、推断、听辨、走神、猜测等错因。“错题巩固”会按每道题最近一次结果汇总仍未掌握的卡点，显示具体学习建议和对应专项入口。确定答对后不再计入旧错因。

本地推荐同时考虑待巩固题、同题型薄弱点和错因，保留相关的新题用于检验迁移。不依赖付费 AI；AI 选题仍是可选操作。

## 题目笔记和笔迹

每题的“本题笔记与手写标注”绑定题号。整卷与专项的同一道题共享笔记；整卷写作、翻译与单独专项也使用相同标识。手写为独立草稿纸，不是直接覆盖 PDF 的绘图层。

文字笔记自动保存，可手动重试保存。笔迹和文字互不覆盖；关闭草稿后仍能选词。数据沿用当前账号的本地数据库与备份，不新增数据库版本，也不会清空旧记录。目前不支持跨设备同步学习明细。

## 空白、失败与恢复

空筛选提供清除入口；真题目录失败可重试，也能转用内置真题；原卷页和音频失败可重试或打开原来源。训练草稿不存在或保存失败时不退出页面，以免丢失当前作答。

## 验证

单元测试覆盖字幕解析与非法时间轴、批改去重/失败重试/过期恢复/整卷分区、最新错因与同类新题推荐。浏览器流程使用独立的本地测试配置、假 AI 凭据及原创 PDF/静音音频夹具，未调用真实付费服务。
